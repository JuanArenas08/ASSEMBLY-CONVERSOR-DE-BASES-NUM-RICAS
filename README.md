# Proyectos de Assembly

Este repositorio contiene dos proyectos desarrollados en lenguaje Assembly x86 de 16 bits como parte de mi formación en la Escuela Superior Politécnica del Litoral (ESPOL).

## Proyecto 1: Conversor de Bases Numéricas

Este programa es un conversor interactivo de bases numéricas que permite convertir números entre las bases decimal, binaria y hexadecimal. El usuario puede seleccionar el tipo de conversión deseada a través de un menú de opciones.

### Características
- Conversiones disponibles:
  - Decimal a Binario (hasta 8 bits)
  - Decimal a Hexadecimal
  - Binario a Decimal
  - Hexadecimal a Decimal
- Validación de entrada según la base seleccionada
- Manejo de errores con mensajes informativos
- Interfaz de usuario intuitiva con menú de opciones

### Instrucciones de uso
1. Abrir el archivo `Proyecto Assemby Org Arenas.asm` en el emulador emu8086
2. Ensamblar y ejecutar el programa
3. Seleccionar el tipo de conversión deseada en el menú
4. Ingresar el número a convertir
5. Visualizar el resultado de la conversión
6. Presionar cualquier tecla para volver al menú principal
7. Repetir los pasos 3 a 6 para realizar más conversiones
8. Seleccionar la opción 5 en el menú para salir del programa

### Tecnologías utilizadas
- Assembly x86 de 16 bits
- Emulador emu8086
